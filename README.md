# creations by bigJ — site

## Wat zit hierin
- `index.html` — de volledige site (1 bestand, HTML/CSS, geen build-stap nodig)
- `images/` — de 5 foto-collages van je creaties

## Lokaal bekijken
Dubbelklik gewoon op `index.html`, opent in je browser.

## Deployen (met Claude Code, drag & drop naar Netlify)
1. Open deze map in Claude Code
2. Vraag Claude Code om:
   - een git repo te initialiseren en naar GitHub te pushen (optioneel maar handig voor latere updates)
   - te helpen met `netlify deploy` (via Netlify CLI) of leg uit hoe je deze map drag & drop naar netlify.com gooit
   - de DNS-instellingen te helpen configureren zodra je een domeinnaam hebt gekocht (bv. bigjcreations.be)

## Later aanpassen
- Foto's vervangen: zet nieuwe bestanden in `images/`, en pas de `src="images/..."` verwijzingen in `index.html` aan
- Tekst aanpassen: alles staat leesbaar in de HTML, gewoon zoeken naar de tekst die je wil wijzigen
- Instagram-link: zoek naar `instagram.com/creations_by_bigj` als je die ooit wil aanpassen
